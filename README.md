# 🚀 Meu Portfólio de Projetos

Bem-vindo ao meu portfólio pessoal! Este projeto foi desenvolvido para centralizar e exibir os meus principais trabalhos e estudos em desenvolvimento web, puxando os repositórios diretamente da API do GitHub.

🔗 **Acesse o site online:** [https://rjyun10.github.io](https://rjyun10.github.io)

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** & **CSS3** (com variáveis e customizações de estilo)
* **Bootstrap 5** (para o layout responsivo e componentes modernos)
* **JavaScript (ES6+)** (para consumo assíncrono da API do GitHub e manipulação do DOM)
* **GitHub API & GitHub Pages** (para listagem dinâmica e hospedagem)

---

## 💻 Funcionalidades

* **Integração Automática:** Busca os repositórios públicos direto do perfil do GitHub de forma dinâmica.
* **Filtro de Testes:** Sistema interno no código para ocultar repositórios que estão em fase de testes ou experimentação.
* **Links Diretos:** Cada card possui acesso rápido tanto para a visualização do projeto rodando no ar (**Ver Site**) quanto para o código-fonte (**Código**).
* **Design Responsivo:** Adaptado para celulares, tablets e computadores com tema escuro (*dark mode*).
